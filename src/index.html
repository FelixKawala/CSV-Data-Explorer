Data explorer

Import one or more CSV files. Each file can become its own dataset, or be added to an existing one. You choose which columns come in, whether each is a dimension to group by or a measure to plot, and what each is called on the page. Everything stays in this browser — nothing is uploaded.

Build a set of plots. Each picks the measures it shows, then drags dimensions between X-axis, Series and Facets — any number can share the x-axis as nested groups. Export any chart, panel or facet as TikZ, pgfplots + CSV, or an image.
