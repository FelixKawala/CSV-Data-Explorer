Data explorer

Toggle applications and data categories on or off to build your own view. Group by application (one card per app, categories nested inside), by category (one card per category, applications nested inside — same metric lined up across applications), or by Device + config (bars grouped by Device/size, one bar per case, so every case sits right next to its peers — each bar carries its own app-code tick label below it, in addition to the color and legend). Device and variant filters scope every panel at once.

Build your own set of plots. Each plot has a grouping priority — drag dimensions to reorder; the bottom two become the chart's axes (series/rows and x/columns), everything above becomes a nested facet (dimensions left at a single value stay invisible filters). Each dimension also gets its own included values list — drag between "shown" and "available," or click ± — so one plot can show just rateA hit rate while another shows Rate A and access count side by side. Both datasets, all Devices, and sizes are available as independent dimensions here.
