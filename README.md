# Data explorer

A single-page tool for exploring tabular data. Any number of dimensions can
share one chart's x-axis as nested groups; plots can be faceted, stacked into
panels, or rendered as a pivot table; and any figure exports to TikZ, pgfplots
+ CSV, or an image.

Runs entirely in the browser. No server, no database.

## This repository holds the tool, never the data

Datasets are loaded at runtime through the import UI and kept in the browser.
Nothing under `evaluation/`, `check/`, `target/`, no `.csv` outside
`test/fixtures/`, and no derived `dataset.json` is tracked — see `.gitignore`.

The test suites therefore run against a **synthetic fixture** generated by
`tools/make-fixture.mjs`, so a fresh clone is testable with no data present.

## Getting started

    npm test        # generate the fixture, then run every suite
    npm run build   # write dist/explorer.html
    npm run serve   # http://localhost:8080

`dist/explorer.html` is self-contained: open it from the filesystem or host it
as a static file.

## Layout

    src/     the app
    test/    jsdom suites + the generated fixture
    tools/   fixture generator and build
    local/   ignored; scratch space for data-specific scripts
